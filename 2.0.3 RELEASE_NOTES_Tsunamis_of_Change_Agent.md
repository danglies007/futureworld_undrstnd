# Release Notes: Tsunamis of Change Agent (Internal Release)

**Release Date:** 2025-05-21

## Overview

Version before crewAI cleanup



This release introduces a completely redesigned frontend interface, enhanced log analysis capabilities, and improved implications formatting. It also includes significant improvements to deployment processes using the UV package manager and adds new custom web scraping tools for more accurate source analysis.

## Major Changes

- **New Streamlit Frontend**

  - Completely redesigned user interface with a modern, intuitive layout
  - Tabbed interface for separate Market Forces Scanner and Competitor Analysis tools
  - Improved configuration options with better user controls
  - Real-time process monitoring and log viewing capabilities
- **Log Analysis System**

  - New standalone log analyzer for LiteLLM and CrewAI logs
  - Detailed metrics extraction including model usage, costs, and timing information
  - Task and crew execution tracking with performance insights
  - Export capabilities for metrics in human-readable and JSON formats
- **Implications Formatting Improvements**

  - Added dedicated ImplicationsFormattingCrew for better report presentation
  - Enhanced markdown and table formatting for implications reports
  - Improved visualization of market force implications
- **Deployment Enhancements**

  - Improved dependency management using UV package manager
  - Added scripts for generating accurate requirements files
  - Docker deployment configurations for AWS Fargate and Google Cloud Run
  - Validation scripts for ensuring consistent dependencies
- **Custom Web Scraping Tools**

  - Added custom FireCrawl scraping tools for improved website analysis
  - Implemented Crawl4AI custom tool for enhanced data extraction
  - Better handling of source URLs and content extraction

## Technical Improvements

- **Code Organization**

  - Restructured project with clearer separation between frontend and backend
  - Improved modular architecture with dedicated utility modules
  - Better process management with dedicated runner classes
- **Performance**

  - Optimized web scraping and data extraction processes
  - Reduced redundant API calls in market force analysis
  - Improved caching for better resource utilization

## Bug Fixes

- Fixed issues with source URL handling and duplicate detection
- Resolved dependency conflicts between embedchain and chromadb
- Improved error handling in crew workflows
- Fixed edge cases in market force extraction

## Other Notable Updates

- Added example frontend implementation for Foresight
- Improved documentation for cloud deployment options
- Enhanced error reporting and debugging capabilities
- Added MLflow integration for experiment tracking
